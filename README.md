# ISpire Technologies website

This is a static, GitHub Pages-ready website for **ISpire Technologies**. It has no build step or server-side dependencies; the site is served directly from `index.html`.

## Publish with GitHub Pages

1. Create a new repository on GitHub. For a personal site, name it `<your-username>.github.io`; otherwise any repository name will work.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root, or push this project with Git.
3. Open the repository on GitHub and select **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. Wait for the deployment to finish. GitHub will show the published URL in the Pages settings panel.

## Local preview

Open `index.html` directly in a browser. All styling and behavior are contained in that file, so no package installation is required.
